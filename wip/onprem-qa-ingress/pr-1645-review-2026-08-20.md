## Proven

* QA's `allow-corp-vpn-to-ingressgateway` CNP admits 4567/5432 from corp VPN + internal CIDRs
  only, byte-identical to op-dev's, 2026-08-20 — the data path is complete once the Gateway lands.
* `risingwave` on op-qa is Flux-managed by this repo (`risingwave-operator` Kustomization) and
  carries no owner label, 2026-08-20.

* QA's ingress already binds hostPort 4567 and 5432 — the Gateway is the only missing piece
  of the data path, 2026-08-20.
* `ghostunnel-rw-sql` and `ghostunnel-rw-postgres` exist in `risingwave` on QA, 9 days old.
* QA's external-dns has logged nothing about either dev hostname in 24h — because the
  `istio-virtualservice` source resolves gateways first and skips the object when one is
  missing. The missing Gateway is what has kept QA away from dev's records.
* Both dev names resolve to dev's seven workers and are live, 2026-08-20.

## Tested and killed

* **Porting the Gateway on its own, as the ticket literally asks.** Rejected: it activates two
  VirtualServices still carrying dev hostnames, so QA's external-dns adopts them, and the
  subsequent rename deletes dev's live records. The ticket's stated scope is not safe on its own.

## Traps

1. **A missing Gateway costs the route AND the DNS record.** external-dns skips a
   VirtualService whose gateway will not resolve, so no record is ever created — and no error
   appears on either object. Same family as `SecretSynced` and `Synced Healthy`.
2. **A correct destination hides a wrong hostname.** These routes pointed at the right QA
   Services the whole time; only the advertised name and target were foreign, which is
   invisible from inside the cluster.
3. **`--policy=sync` on a zone-wide filter makes hostname renames destructive.** What a
   cluster stops wanting, it deletes. Ordering is a correctness property, not a preference.
4. **An ownership rule without a cluster attached reads as a contradiction.** `pr-review-rw`
   and the `risingwave-onprem` memory disagreed only because both describe op-dev and neither
   said so. Nothing was stale. Scope every ownership claim to a cluster.
