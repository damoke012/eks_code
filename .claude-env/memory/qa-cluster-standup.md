⚠️ **Client version skew was my hypothesis and it was WRONG** — `talosctl:v1.10.4` works fine against the v1.11.1 server. Don't re-derive it. Diagnostic lessons: (a) comparing the config's CA to `openssl s_client` output compares a CA against the server **leaf** (`CN=talos-cp-op-qa-1`) — inconclusive, NOT evidence of drift; (b) hash-compare the mounted secret against SM in FULL (`diff`), not `head -c 20` — the only delta here was a trailing newline from `--output text`; (c) after merging a Flux fix, **`flux reconcile kustomization <name> --with-source` and confirm the LIVE object changed before re-testing** — a stale spec and a real failure produce identical output. Pods are GC'd fast, so poll `kubectl -n etcd-backup get pods -l job-name=$J` in a loop right after creating the job.
